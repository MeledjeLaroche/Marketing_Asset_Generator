## 🚀 Why Nano-Banana Studio?

Tired of booking expensive photoshoots just to get your product on a billboard, an Instagram post, and a magazine cover? 

**Nano-Banana Studio** is a next-gen AI application that takes a single text description of your product and seamlessly hallucinates it into **any marketing support**—from glowing bus stops to sleek print ads—while maintaining **perfect visual consistency**.

### ⚡ Superpowers

*   **🪄 1-Prompt Magic**: Describe your product once. Our engine generates a pristine, isolated reference image. 
*   **🖼️ Infinite Supports**: Place your product in realistic environments (Billboards, Social Media, Magazines, Web Banners).
*   **📐 Adaptive Formats**: Need 16:9 for a banner? 9:16 for a reel? 1:1 for a post? We got you. Built-in ratio adaptation.
*   **👻 Absolute Zero Human Presence**: We enforce strict "no human" prompting under the hood. Only your product gets the spotlight. No weird AI hands.
*   **🎨 Bento Grid UI**: A gorgeous, dark-mode, brutalist-inspired UI that makes you feel like a futuristic art director.

---

## 🛠️ How it Works

1.  **Define:** Type detailed description of your product (e.g., "Minimalist smoked glass perfume bottle with brushed aluminum cap").
2.  **Lock in:** The AI generates a base reference image.
3.  **Deploy:** Select your format (Billboard, Insta post), aspect ratio, and resolution.
4.  **Export:** Download your pixel-perfect marketing asset.

---

## 💻 Tech Stack

*   **Frontend**: React 19, TypeScript, Vite
*   **Styling**: Tailwind CSS v4 (Bento Grid layout)
*   **Icons & Animation**: Lucide React, Motion
*   **AI Engine**: Google `@google/genai` using the ultra-fast `gemini-2.5-flash-image` model.

## 🚦 Quick Start

```bash
# Clone the repository
git clone https://github.com/your-username/nano-banana-studio.git

# Navigate into the project
cd nano-banana-studio

# Install dependencies
npm install

# Start the ultimate generation engine
npm run dev
```

> **Note**: You will need a Google Gemini API Key. The app expects an API key configured in the environment.
